# Try_Hack_Me_Writeups

| Type | Meaning |
|---|---|
| **Walkthrough** | Step-by-step solve of a CTF/challenge room, including the reasoning and dead ends |
| **Writeup** | Reference notes from a guided/educational room |
| **Report** | Formal, report-style write-up of an engagement |

File naming: `TryHackMe - <Room Name> - <Type>.md`
